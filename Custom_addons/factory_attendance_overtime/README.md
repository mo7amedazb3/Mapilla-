# اعتماد الإضافي

قائمة مستقلة للأدمن لمراجعة الوقت بعد نهاية الشيفت حسب يوم الحضور. كل حالة
تظل بحاجة للاعتماد حتى يختار الأدمن اعتماد الوقت الظاهر، رفض الإضافي، أو إدخال
وقت انصراف يدوي واعتماده. الرواتب المخصصة تحتسب الدقائق المعتمدة فقط.

يغلق النظام الحضور المفتوح عند منتصف الليل بتوقيت العامل. وإذا وصلت بصمة خلال
الساعات الأولى بعد منتصف الليل، تُحفظ كبصمة خام وتُربط بانصراف اليوم السابق
للمراجعة بدل إنشاء حضور جديد.

كل قرارات الاعتماد محمية بقفل الموظف وقفل سجل الحضور، وتُرفض الطلبات القديمة
أو المتعارضة مع حضور أحدث. تظل الرواتب المؤكدة والمدفوعة ثابتة، وتُحدّث مسودات
الرواتب المتداخلة مع يوم القرار فقط.
